# App previews

The screenshots used by the main README were captured on 2 October 2026 from
**LumaBridge running natively on Windows**, using its Direct3D 11 interface and connected
hardware. They are not Linux, Wine or offscreen demo renders.

The running executable was the Azoth inactivity test build preceding v0.37.1; its sidebar
still displays v0.37.0. The screenshots include the inactivity behavior released in v0.37.1.

| Image | View |
|---|---|
| [app-lighting.png](app-lighting.png) | Auto lighting, the desktop gradient and connected-device overview. |
| [app-dashboard.png](app-dashboard.png) | Live CPU, GPU, memory and power readings alongside lighting status. |
| [app-mysetup.png](app-mysetup.png) | The PC and three-monitor desk, with live lighting and hardware labels. |
| [app-azoth.png](app-azoth.png) | Azoth OLED controls and the six custom GIF previews. |

Each PNG captures the app's client area at **1624 × 1021**. The window was temporarily
resized and the 3D view zoomed to fit the desk; lighting and hardware settings were left
unchanged. Images retain the app's actual colors and text.

For replacements, capture the native Windows window at a consistent size, keep the
cursor and other windows clear of the client area, and check that the complete view is
visible. Restore the window size and placement after capture. Update the date and build
information here when refreshing the gallery.

`effects-preview.png` is retained for the historical v0.3.0 release notes and is not part
of the current README gallery.
