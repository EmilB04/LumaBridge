## New: silent hand-back to Armoury Crate

When LumaBridge gives the lights back (idle choice **Armoury Crate**, **Stop controlling
the lights**, or exiting LumaBridge), it can now restore Armoury Crate's effect without
any window or click. It restarts the motherboard's lighting controller, which then
reloads the effect Armoury Crate saved in it.

Set it up once: **Games → Armoury Crate hand-back → Set up**. This needs administrator
approval once and creates a small background task. Without it, LumaBridge opens Armoury
Crate as before.

## Tidier download

```
LumaBridge\
  LumaBridge.exe            the app
  LumaBridge.ini.example
  integrations\             game SDK stand-ins (x86\ for 32-bit games)
  tools\                    hardware tests
  scripts\                  install helpers the app runs for you
```

If you set up Logitech LIGHTSYNC with an older version, open **Games** and click
**Set up** again: the Logitech DLL now lives in `integrations\`.

## New tool: `tools\ram-probe.exe` (read-only)

A first step towards RAM lighting. With the PawnIO driver installed
(https://pawnio.eu) and `SmbusPIIX4.bin` from the PawnIO.Modules release placed next to
it, run it as administrator. It lists which RAM-related chips answer on the SMBus. It
only reads and never writes anything.
