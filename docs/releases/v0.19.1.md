> **Pre-release.** Closing LumaBridge closes it.

## Fixed

- Closing the window (its X, or Close window from the taskbar) hid LumaBridge in the tray,
  where it kept running in the background. Closing now exits it, and the lights go back to
  Armoury Crate. Minimize the window to keep LumaBridge running.
- Exiting always ends the process now: if something hangs while shutting down, LumaBridge
  ends itself after a few seconds.

## Changed

- If you prefer the old behaviour, turn on **Settings > Startup > Closing the window keeps
  LumaBridge in the tray**. Exit is then in the tray icon's menu.
