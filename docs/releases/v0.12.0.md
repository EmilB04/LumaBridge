> **Pre-release.** A setup guide, pages that adapt to your PC, and any brand's Windows Dynamic Lighting devices lit directly.

## New

- **Setup guide.** On first start (and from Settings) LumaBridge asks which RGB hardware and
  lighting software you have, ticking what it finds itself; shows the devices it found and
  asks for the fans on the ARGB header (count, LEDs per fan, test pattern); then sets up its
  connections - all on, except where your answers rule one out (such as Razer Chroma games
  while Synapse is installed). Each one is checked after it's set up.
- **Windows Dynamic Lighting devices.** Keyboards, mice, headsets, cases and light strips of
  any brand with Windows 11's lighting standard (HID LampArray) in their firmware follow
  LumaBridge and your games lamp by lamp, with no software from their maker. Not yet tried on
  a real device - feedback welcome.
- **Only the devices your PC has.** The Devices list, the dashboard, the Lighting page and the
  setup preview show only what's there: a Logitech mouse without RGB is left out (and named
  as such), no keyboard without an Azoth, no memory unless it's RGB memory LumaBridge can
  light, no fans without an Aura ARGB header. Logitech devices are named after what was found.
- **More ASUS boards.** Other generations of the motherboard's AURA LED Controller are looked
  for too, not only the one on the ROG STRIX B550-F. Not yet tried on those boards.
- **More hardware recognised.** RGB gear from Razer, SteelSeries, Corsair, NZXT, Cooler
  Master, Thermaltake, MSI, Keychron, Alienware and Gigabyte RGB Fusion, and Corsair / G.Skill
  RGB memory, is named on the Devices page and in the guide, with how it can be lit.
- **OpenRGB, only if you already use it.** Off unless OpenRGB is on the PC; then what it
  supports can follow LumaBridge too. LumaBridge never needs it.

## Changed

- The ROG Azoth and memory lighting are on by default for new installs.
