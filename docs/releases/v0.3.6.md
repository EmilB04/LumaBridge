> **Pre-release.** A dashboard with the essentials: lighting, the running game, CPU, GPU,
> memory, fans, temperatures, your Aura devices and connections.

## New

- **Dashboard** (the new first page). Cards with drawn icons, laid out in two or three
  columns depending on the window width:

  | Card | Shows |
  |---|---|
  | Lighting | Mode, what's showing and the effect, the hand-back countdown |
  | Game | Running games and whether they drive the lights, show screen colors or wait |
  | Processor | CPU name, load, temperature, threads |
  | Graphics | GPU name, load, temperature, fan, VRAM, power |
  | Memory | Use, plus your sticks by product name (e.g. "2 x 8 GB HyperX FURY @ 3600 MT/s") |
  | Fans | Every fan's speed, with icons spinning at their speed; unused headers counted |
  | Temperatures | CPU, GPU, board, drives, colored green / amber / red |
  | Aura devices | Friendly names ("ASUS ROG STRIX B550-F GAMING lighting", "Fans (3 x 20 LEDs)") |
  | Connections | Every integration and game feed at a glance |
  | System | Board, BIOS, CPU, GPU, memory, LumaBridge version |

  **Customize** shows or hides each card and changes the order. The layout is saved.
- **Where the numbers come from:**
  - Component names come from the firmware (SMBIOS) and DirectX.
  - CPU load and memory come from Windows.
  - NVIDIA GPU stats come from NVIDIA's own library, which ships with the driver.
  - Motherboard fan speeds and CPU / board temperatures need a kernel driver to read, and
    LumaBridge deliberately doesn't install one. They come from LibreHardwareMonitor (free,
    open source) when it's running with Options → Remote Web Server → Run (port 8085; change
    it with `[Dashboard] LhmPort`). The cards say so, with a download button, when it isn't.
  - Data is only collected while the dashboard (or Devices page) is open.
- **Devices page:** friendly names and icons (the original name is in the tooltip).
