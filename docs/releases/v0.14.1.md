> **Pre-release.** Memory slots you can set yourself.

## Fixed

- **Memory in the setup preview.** Some boards' firmware names the memory slots differently
  from how they sit on the board, so the preview could draw a stick in the wrong slot. The new
  **Memory slots** card (Devices > Memory, and in the setup guide) shows what your board calls
  each slot and lets you set the filled slots yourself (A1 A2 B1 B2, from the CPU outward);
  "As the board says" goes back to the firmware's answer.
- **More boards' slot names are understood:** the channel in the bank locator
  ("P0 CHANNEL A" / "DIMM 0"), channels numbered from zero, and slots numbered in a row.
