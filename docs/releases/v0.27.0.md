> **Pre-release.** A real status on the ROG Azoth's page when it can't be found.

## New

- **ROG Azoth diagnostics:** its Settings card now shows whether it's active (wired or
  wireless), handed off, or not found - with a Windows error code when a write actually
  failed, or a note that it's simply not been found yet otherwise. Clarified in the card and
  in `docs/peripherals.md`: **Armoury Crate isn't needed** - LumaBridge talks to the keyboard
  directly over raw HID. Detection only matches two known USB product IDs; a different
  region, SKU or firmware revision reporting a different one won't be found - that's now
  visible instead of silent. Checked: compiles and runs (built and launched on Windows this
  round); the specific "not found" path itself is unverified against a real mismatched-PID
  Azoth, since none is available to test against.
