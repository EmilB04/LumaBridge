> **Pre-release.** The window no longer goes white and "Not responding" while LumaBridge opens.

## Fixed

- **Freeze at start:** the first page asked Windows, twice, whether the Armoury Crate hand-back
  and hardware access tasks are set up, and waited for each answer. On a busy PC that took
  seconds, so the window showed white and "Not responding". The question is now asked in the
  background while the window opens. Until Windows answers, those two entries say "Checking...".
  The same wait after a setup or remove action is gone too.

## Changed

- "Connect all games" leaves hardware access and the hand-back alone until Windows has
  answered, so it can't ask for administrator approval by mistake.

## Validation

- The x64 Windows app builds with MinGW and the Linux core tests pass. The published package
  is built with MSVC by the release workflow.
- Not checked: how long the wait was on the affected PC, because the log doesn't record it.
  Start the app a few times, also right after logging in, and tell me if the window still
  goes white.
