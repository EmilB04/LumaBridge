> **Pre-release.** Bug fixes for v0.2.5.

## Fixed

- **Motherboard and fans flickered every few seconds** while LumaBridge controlled them.
  LumaBridge re-sent the controller's "direct mode" command every 2 seconds, which
  blanks the LEDs for an instant. It is now sent once when LumaBridge connects; the color
  itself is still refreshed every second.
- **"Lighting control paused" after restarting Windows.** When Windows shuts down or
  restarts, LumaBridge now records a clean exit, so a normal reboot no longer looks like a
  crash.

## Download

**LumaBridge-v0.2.6.zip** below. Exit the running LumaBridge from the tray first, then
