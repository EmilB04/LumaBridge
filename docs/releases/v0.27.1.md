> **Pre-release.** Rocket League's orange is orange again, and the Azoth stays lit during a game.

## Fixed

- **Rocket League colors:** last round's fix for muted team colors (forcing saturation up on
  a dim color) turned an orange team color pink - small, numerically unstable channel
  differences in a merely dim color got amplified into the wrong hue. Replaced with a
  brightness-only boost: it can brighten a dim color but can never change its hue or
  saturation, so this can't happen again. A gray team color now stays gray, just brighter,
  instead of getting an invented hue.
- **ROG Azoth falling asleep mid-game:** "Refuse to sleep while a dynamic effect is showing"
  (added last round, off by default) is now **on by default** for the Azoth. A game played
  with a controller never touches the keyboard, so the old default timeout faded it out
  mid-match despite active game lighting. Already-running installs keep whatever they last
  saved for this switch (Settings > the Azoth's page) - it isn't overridden retroactively.
  Logitech devices have the same switch if a mouse hits the same issue; left at its previous
  default since it wasn't reported.
