> **Pre-release.** Keep the mouse and keyboard awake through a dynamic effect.

## New

- **Refuse to sleep while a dynamic effect is showing:** a new switch on the mouse's and the
  ROG Azoth's pages (off by default), next to the existing fade-out timer. On: the device
  skips its sleep timeout entirely while its current effect isn't a plain static color - a
  game, or an animated preset like Rainbow or Comet - so it doesn't fade out and go dark
  mid-effect. A still color still fades and sleeps on its usual timer. **Not checked in the
  running app** (no Windows build available this round).
