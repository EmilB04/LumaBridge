> **Pre-release.** Hardware test tool fix; the app itself is unchanged.

## Fixed: `aura-usb-test.exe scan` / `color`

The motherboard's Aura controller numbers channels one way for switching modes and
another way for sending colors. v0.2.3 used the same number for both, so LEDs went dark
instead of showing red. The tool now switches every channel to direct mode first, then
lights one color channel at a time.

## Test

1. Quit Armoury Crate (Task Manager → end `ArmouryCrate.exe` and
   `ArmouryCrate.UserSessionHelper.exe`).
2. In PowerShell in the LumaBridge folder: `.\aura-usb-test.exe scan`, then note what
   turns red for each channel number (motherboard LEDs, fans, nothing).
3. Reopen Armoury Crate or reboot to restore your normal lighting.
