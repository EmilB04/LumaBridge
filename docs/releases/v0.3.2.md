> **Pre-release.** A Games List of everything installed, a hand-back that survives Armoury
> Crate holding the controller, and setup buttons that tell you what happened.

## New

- **Games List page:** every game installed on the PC, found in Steam and Epic's
  manifests, the Windows installed-apps list (EA, Ubisoft, GOG, Riot, Rockstar,
  Battle.net, ...), Xbox game folders and the games Windows' Game Bar knows. Each game
  shows whether it does dynamic lighting:
  - **Lighting now:** it's running and driving your lights.
  - **Supported:** LumaBridge has seen it send lighting before.
  - **Likely:** its folder contains a lighting SDK's files (e.g. Corsair iCUE).
  - **Not detected:** nothing seen yet. Some games build the SDK in, so play once to be sure.
  Running games are listed first. **Add a game...** lets you pick any .exe. Added games
  are recognised as games whenever they run (Auto mode, "Running") and can be removed.
  Only file names are looked at, never a running game's memory.
- The old **Games** page is now **Integrations**.
- **`tools\ghub-probe.exe`:** a read-only probe of Logitech G HUB's local connection. It
  answers whether LumaBridge could mirror what games send to G HUB (e.g. Battlefield 1,
  whose anti-cheat keeps LumaBridge's DLL out) without going near the game. It only
  lists and listens (GET / SUBSCRIBE requests, never SET) and saves its findings to
  `%LOCALAPPDATA%\LumaBridge\ghub-probe.txt`.

## Fixed

- **Hand-back needed a reboot to take effect.** Right after boot, Armoury Crate's
  motherboard helper (`Aac3572MbHal_x86`) keeps the lighting controller open. Windows
  then can't restart the controller live, so it queued the restart for the next reboot
  and refused every later attempt ("Device is pending system reboot"). The hand-back
  task now checks, without touching anything, whether the controller is in use. If it
  is, the task stops that helper (Armoury Crate starts it again by itself). It only
  restarts the controller when nothing holds it, and otherwise logs what does.
  **If an earlier hand-back left the controller "pending reboot", restart Windows once.**
- **Hand-back can be set up again.** After it was set up once, the page only
  offered Remove. It now has **Set up again**, and asks you to **Update** when the task
  was set up by an older LumaBridge. (This release needs that: Integrations → Armoury
  Crate hand-back → **Update**, once.)
- **Set up / Install buttons seemed to do nothing.** The administrator prompt could
  open behind LumaBridge. It now opens in front of it, the card shows "Waiting for you
  to approve..." while it waits, and the result appears right under the button.
  Everything the setup scripts print goes to `setup.log` in the log folder.
- **Logitech pass-through finds current G HUB** (`LGHUB\sdks\sdk_legacy_led_x64.dll`).
- Game names no longer show "™" / "®" (e.g. "Battlefield 1").
- LumaBridge no longer opens Armoury Crate when a hand-back is requested while the
  previous one is still running, and it waits for the task to finish before copying
  its result into the app log.
