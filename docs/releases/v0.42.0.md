> **Pre-release.** A still power-on color for the motherboard and fans, and effects that travel across your setup.

## New

- **Color at power-on:** on the motherboard's or an ARGB header's page under Devices, pick
  a color and click "Save as power-on color". The board's LEDs and every ARGB header (fans,
  strips) then show that still color from power-on, before Windows and LumaBridge start,
  instead of the effect saved in the board (often a rainbow). It is stored in the board's
  controller, so it is only written when you click; saving an effect in Armoury Crate
  replaces it. RAM sticks can't store a color and keep their own rainbow until LumaBridge
  starts.
- **Effects travel across your setup:** on the Lighting page (Manual), under "Your setup",
  choose Left to right, Right to left, Top down or Bottom up, and how long the effect takes
  from the first device to the last. Moving effects (breathing, color cycle, rainbows,
  comets) then reach each device in turn, by where it sits in the 2D layout. Fans on one
  ARGB hub get the same signal and move as one. Games still light every device at once.

## Validation

- The x64 Windows app builds without warnings; Linux core tests pass, with new tests for
  the power-on commands (effect channel numbering, color masks, save command) and for the
  flow (positions, offsets, effect timing).
- Checked both new cards in a Wine UI preview.
- Not yet checked on real hardware: the power-on save on the owner's ROG STRIX B550-F
  (sequence as OpenRGB's ASUS Aura USB driver sends it) and the flow with lit devices.
