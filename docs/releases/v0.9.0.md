> **Pre-release.** The ROG Azoth lit key by key.

## New

- **ROG Azoth: every key its own color.** By cable, LumaBridge now draws every effect across
  the keyboard key by key: waves, gradients, Fire, comets and twinkle run from left to right,
  and games light every key. Only the keys that change are sent, up to about 25 times a
  second, and nothing is saved to the keyboard.
  - Through the ROG Omni receiver the keyboard still shows one color for now.
  - The key map is for the ISO / Nordic Azoth; an ANSI (US) Azoth needs its own map first.
- **The preview's keyboard** shows the same keys, ISO layout and all, each with its own color.
- **`tools\azoth-probe.exe`** tests the Azoth's per-key lighting and maps its keys: one key
  lights at a time and you press it.
