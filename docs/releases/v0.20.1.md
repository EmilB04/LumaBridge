> **Pre-release.** Memory slots you can see, and the Kraken read alongside NZXT CAM.

## Fixed

- **Memory slots** (Devices > Memory, and the setup guide) are drawn as the board has them:
  the CPU, then slots A1, A2, B1 and B2 outward, a stick in each one that's used. Click a
  slot to put a stick in or take it out; hover one to see which it is.
- **NZXT Kraken "No reply" / "Windows won't let LumaBridge open it":** with NZXT CAM running,
  CAM keeps the Kraken to itself for sending, so LumaBridge couldn't ask it for its status.
  LumaBridge now opens it to listen only and reads the status replies CAM asks for (liquid
  temperature, pump and fan speeds), so it works with CAM running. The Kraken's card also
  shows Windows' error code if it still can't open it.
