> **Pre-release.** One-click hardware access, and fan speeds and temperatures without LibreHardwareMonitor.

## New

- **One click, nothing to download.** Devices → **Hardware access** → **Set up** (one
  administrator approval) sets up everything RAM lighting and the sensors need:
  - PawnIO, the small signed driver that gives access to this hardware, now comes with
    LumaBridge (`pawnio\`, unmodified) and installs silently.
  - LumaBridge's own helper, which LumaBridge then starts by itself.
  - Switching on **Light the RAM** runs the setup too if it hasn't been done.
- **Sensors without LibreHardwareMonitor.** Once Hardware access is set up, the dashboard's
  Fans, Temperatures and Processor cards read the hardware themselves:
  - the Ryzen CPU temperature;
  - fan speeds and the motherboard / CPU socket temperatures from the board's Nuvoton
    NCT679x monitoring chip (most ASUS AMD boards).

  Fan names follow the usual ASUS wiring; tell us if one doesn't match your BIOS.
  LibreHardwareMonitor still works as a fallback for other boards, but isn't needed.
- **No PawnIO library.** LumaBridge now talks to the PawnIO driver directly.

## Fixed

- **RAM lighting froze on the last color when switched off.** LumaBridge now hands the sticks
  back when it lets go: when you switch it off, when the lights go back to Armoury Crate, and
  when LumaBridge exits. Choose what they show then on the Memory card:
  - their own rainbow (the default);
  - off;
  - keep the last color.

## Changed

- The RAM-only helper of 0.5.x is replaced by `LumaBridge-Helper.exe` (RAM and sensors).
  Setting up Hardware access removes the old one. If you set up RAM lighting in 0.5.x, click
  **Set up** once more.
- A failed setup now shows its reason in the app instead of only "exit code 1". It also
  finds the PawnIO driver wherever it's installed.
