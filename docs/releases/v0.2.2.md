> **Pre-release.** Still being verified on real hardware.

## New

- **Works alongside SteelSeries GG.** LumaBridge now passes every GameSense message on
  to GG as well, so GG keeps working while LumaBridge lights your Aura devices. That
  includes **Moments** auto-clips and any SteelSeries devices. If GG restarts,
  LumaBridge follows it automatically. The Games page shows the forwarding status.

## Safer

- **Games can no longer be crashed by ASUS's Aura library.** On some systems an Armoury
  Crate device plug-in (`AacKbHal_x64.dll`) terminates whichever program loads it. The
  Logitech, Razer, Corsair and Alienware parts of LumaBridge that run inside games now
  only hand their colors to the LumaBridge app and never load the Aura library in the
  game. Game lighting therefore needs the LumaBridge app running.
  (`[Aura] DirectFromGames=1` restores the old behaviour.)

## Diagnostics

- The log now records how the Aura SDK is installed (in-process DLL or service, 32/64-bit)
  and each step of finding devices, plus crashes that happen inside other vendors' DLLs.

## Known issue

- On some systems the Aura SDK finds **0 devices**, or crashes in ASUS's keyboard
  plug-in while listing them. To check your PC, run `aura-test.exe list` from a command
  prompt in the LumaBridge folder.
