> **Pre-release.** Direct Azoth GIF uploads, more animations, and experimental live audio and song displays without Armoury Crate.

## New

- **Azoth USB GIF upload:** select a LumaBridge animation and upload it directly to the
  keyboard, with progress and cancellation. Armoury Crate is not required. Direct upload
  has been confirmed on the original ROG Azoth with a USB cable.
- **More animations:** 18 LumaBridge effects, including Spiral, Plasma, Tunnel, Bounce,
  Pulse, Fireworks, Orbit, Checker, Ribbons, Mountains, Comet and Dots.
- **Audio EQ:** an experimental live 32-band spectrum from the default Windows playback
  device. Requires USB and LumaBridge running; pauses when the keyboard sleeps.
- **Song info:** an experimental title and artist display from the current Windows media
  session. Updates when the track changes and shortens long lines to fit. Requires USB
  and a player that shares its song information with Windows.

## Changed

- **Smaller previews:** compact animation tiles adapt to the available width and show
  the whole collection. GIF export and the Armoury Crate guide remain available as a
  collapsed fallback.
- **OLED menu:** choose Keep current, Animation, Clock, Audio EQ or Song info. The selected
  mode and animation are saved with the existing settings.

## Validation

- The x64 app builds, portable tests pass, and the updated UI was checked in Wine.
- Native Windows checks opened playback capture and read a player's song title and artist.
- Physical EQ and song display still need validation on the original Azoth. These modes
  use separate music commands and do not upload to the custom GIF slot. Turn off Armoury
  Crate's live OLED modes if they overwrite LumaBridge's display.
- Direct GIF uploads remain USB-only; importing your own GIF files is not implemented.
