> **Pre-release.** A redesigned app: presets for every effect, a customizable rainbow, and a page per game.

## New

- **Presets for every effect.** Lighting → Manual shows ready-made looks for the chosen
  effect as tiles with a live preview: gradients like Sunset, Ocean, Aurora, Cyberpunk and
  Peach; rainbows like Pastel, Double, Fire and Vaporwave; comets, twinkles (Starry night,
  Fireflies, Embers), breathing and strobe looks. One click applies it.
- **Customize the rainbow.** For Color cycle and Rainbow wave: the starting hue, the range of
  hues (full spectrum or just a part of it, e.g. only blues), color intensity (vivid to
  pastel) and how many rainbows go around each fan. Auto mode's rainbow between games uses
  the same settings.
- **Reverse direction** for Rainbow wave, Gradient and Comet.
- **Both colors get the full editor.** The second color (Gradient, Comet background, Twinkle
  sparkles) now has the same color wheel, hex input, swatches and recent colors as the first.
  Pick which one to edit with the two color tabs; Swap is still there.
- **A page for every game.** Click a game on the Games List to customize it: what the lights
  show while it isn't sending lighting (Default, Screen colors, your idle choice, or a new
  **own color** just for that game), and removing games you added.
- **Built-in games moved to the Games List.** Counter-Strike 2, Rocket League and War Thunder
  now have tiles at the top of the Games List with their status; click one to set it up.

## Changed

- **Modern look:** switches instead of checkboxes, pill-style tabs, a sidebar with icons,
  icons on the cards, and a page subtitle.
- **Dashboard:** cards in a row now have the same height, so the grid is even.
- **Devices:** the motherboard and fan icons line up with their names.
- **Settings:** "Stop controlling the lights" is gone; the Auto / Manual switch covers it.
  (The tray menu still has it.)
