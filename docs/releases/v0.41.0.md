> **Pre-release.** A simpler Integrations page, steadier ASUS lighting through keyboard reconnects, and defuse guides and an explosion animation on the Azoth's CS2 countdown.

## New

- **One integration switch:** enable Logitech, Razer, SteelSeries and Alienware game
  connections together, plus Windows lighting and OpenRGB. Edit connections to turn off
  individual integrations, repair setup or choose Corsair game folders. OpenRGB still needs
  its SDK server running; Corsair game folders are managed separately.
- **CS2 defuse guide:** the Azoth countdown shows the time needed with a kit (5 seconds)
  and without one (10 seconds), using a wire-cutter icon beside the timer.
- **Bomb explosion:** a confirmed CS2 detonation plays a short explosion animation before
  restoring the selected OLED screen. An estimated timer reaching zero does not trigger it.

## Fixed

- **Motherboard and fan flicker:** connecting or disconnecting a keyboard no longer causes
  repeated motherboard lighting resets. While LumaBridge controls ASUS lighting, the helper
  blocks LightingService restarts and saves its original startup setting for restoration.
- **RAM bus held by ASUS software:** when native RAM lighting needs the memory bus and
  ASUS lighting has stopped, the helper can release known ASUS RAM lighting workers that
  still hold it. Other applications are left alone.
- **Armoury Crate hand-back:** exit releases the motherboard before restoring the ASUS
  service. The hand-back task checks for held handles and restores the original service
  startup setting, retaining failed restoration state for retry.
- **Unavailable Azoth actions:** OLED controls are greyed out without a supported USB or
  Omni connection, during sleep or while the keyboard is unresponsive. USB-only actions
  remain unavailable through the wireless receiver; Bluetooth OLED control is unsupported.

## Changed

- **Clearer device status:** connection information such as wired USB, wireless receiver
  and lighting source replaces repetitive per-key wording.
- **Azoth animation menu:** LumaBridge GIF choices sit directly below the animation
  collection switcher, in the same place as ASUS built-in choices.
- **Confirmed OLED features:** the countdown test controls and GIF test wording have been
  removed after confirmation on the owner's keyboard. The defuse guide is vertically centered.
- **Update hardware support:** under Integrations -> Edit connections, update Hardware
  access and Armoury Crate hand-back if prompted. Both use task version 7. Turning game
  integrations off keeps hardware access and Armoury Crate hand-back installed.

## Validation

- The x64 Windows app and helper build; Windows core and hand-back tests and Linux core
  tests pass. Tests cover service restoration, worker paths, integration setup rules,
  countdown rendering and explosion timing.
- Checked the Integrations page at normal and narrow widths in an isolated UI preview.
- The owner confirmed wired countdown operation and GIF uploads. The new disconnect,
  RAM and hand-back behavior and the explosion animation still need real-hardware checks.
