> **Pre-release.** A collapsible sidebar, for narrow windows and small screens.

## New

- **Collapsible sidebar:** click the chevron at the top of the sidebar to switch it to
  icon-only (hover an icon for its name). It also collapses on its own once the window gets
  too narrow for both the sidebar and the page beside it to fit comfortably, and expands
  again once there's room - your own choice always wins when there is room. **Not checked in
  the running app** (no Windows build available this round) - built with the same layout
  patterns already used elsewhere on the page (the responsive dashboard grid, the hover
  cursor on the nav items).
