Bug-fix release for v0.2.0.

> **Pre-release.** Still being verified on real hardware. Please report what works.

## Fixed

- **LumaBridge closed a few seconds after starting** (and every time after that) as soon
  as it took control of the Aura lights, e.g. after switching to Manual mode. LumaBridge
  now talks to the Aura SDK the same way ASUS's own samples do (single-threaded COM
  apartment).

## Improved

- If LumaBridge ever closes unexpectedly while controlling your lights, the next start
  leaves them to Armoury Crate and shows a **Resume lighting control** button, instead
  of crashing again.
- Crashes are written to the log (`Settings → Open log folder`) together with a
  `LumaBridge-crash.dmp` file, and each step of connecting to Aura is logged.

## Download

**LumaBridge-v0.2.1.zip** below. Unzip over the previous version, or into a new folder,
and run `LumaBridge.exe`. Your settings are kept (`%LOCALAPPDATA%\LumaBridge`).

Quick hardware check: open a command prompt in the folder and run `aura-test.exe list`.
It lists the Aura devices LumaBridge can control.
