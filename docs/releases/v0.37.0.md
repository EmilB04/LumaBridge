> **Pre-release.** The fans and the Logitech mouse go dark while the PC sleeps and come back on wake, and a resting wireless mouse is left alone so it can sleep.

## New

- **PC sleep:** before Windows sleeps, LumaBridge turns the fans and the Logitech lighting
  off and pauses its updates. On wake it reconnects and puts the current lighting back. If
  Windows doesn't report the wake, LumaBridge restores the lighting by itself after half a
  minute.

## Changed

- **Mouse power saving:** after the fade when you're not using it, the Logitech mouse gets
  one final "off" and then no lighting updates or receiver queries at all until you use it
  again, so a wireless mouse can really sleep (LumaBridge's device scans no longer wake it).
- **Stay awake while a game controls the lighting** (was "Refuse to sleep while a dynamic
  effect is showing"): only an active game's lighting keeps the mouse and the ROG Azoth
  awake now. Your own colors and animated presets fade and sleep as usual.

## Fixed

- **Mouse effect kept running when idle:** a black frame doesn't stop every onboard
  effect, so the mouse now switches to a fixed black effect (and G HUB's color is darkened
  too) when it sleeps.
