> **Pre-release.** Experimental Sony DualSense lightbar support.

## New

- **DualSense lightbar (experimental, unverified):** a PS5 DualSense controller's lightbar
  now follows LumaBridge's effect, as one color, by USB cable or Bluetooth - no Steam or
  other software needed, LumaBridge talks to the controller directly. Player-indicator LEDs
  are left off. Set up like any other device: found automatically, its own page under
  Devices, on by default. The output report layout is reimplemented from OpenRGB's open-source
  DualSense driver (documented byte offsets, not copied code) since LumaBridge has no
  DualSense of its own to capture from - **this has not been checked against a real
  controller.** The byte layout and the Bluetooth report's CRC-32 are covered by the portable
  unit tests and pass, and the app builds and runs (checked on Windows this round), but the
  actual hardware behavior is unverified. If you try it, a report of what happened (working
  or not) is genuinely useful.
