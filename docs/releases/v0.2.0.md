First public build of LumaBridge: dynamic game lighting on ASUS Aura Sync devices
(motherboard, RAM, fans, GPU, Aura keyboards such as the ROG Azoth), including in games
that only support other brands.

> **Pre-release.** Everything builds and the unit tests pass, but this version has not
> been verified on real hardware yet. Please report what works and what doesn't.

## Download

**LumaBridge-v0.2.0.zip** (below). Unzip it anywhere, e.g. `C:\Program Files\LumaBridge`,
and run `LumaBridge.exe`. Requires Windows 10/11 and Armoury Crate (Aura's lighting service).

## What's in it

- **LumaBridge app**: Auto mode (games drive your lights) and Manual mode (color wheel,
  presets, breathing/strobe, brightness), color calibration, per-device on/off, one-click
  game integrations, tray icon, start with Windows.
- **Game lighting SDKs** answered by LumaBridge:
  - Logitech LIGHTSYNC (e.g. Battlefield 1). Logitech devices keep working.
  - Razer Chroma
  - SteelSeries GameSense (built into the app)
  - Corsair iCUE SDK 2/3 (per game folder)
  - Alienware AlienFX
- **Tools**: `aura-test.exe` (list Aura devices, set colors) and `logiled-harness.exe`
  (simulates a LIGHTSYNC game).
- 32-bit DLLs for older games in `x86\`.

## Getting started

1. Run `LumaBridge.exe`, switch to **Manual** and pick a color. Every Aura device should
   follow. **Devices** lists what Aura found.
2. Open **Games** and set up the SDKs you want.
3. Start a game. It appears on the **Lighting** page and your Aura devices follow it.

## Known limits

- All Aura devices show one color at a time. Per-key effects on the Azoth are planned.
- Some newer Razer Chroma titles verify Razer's signature and ignore LumaBridge.
- Corsair iCUE SDK 4 (2022+ titles) and Windows 11 Dynamic Lighting aren't supported.
- Logs for troubleshooting: **Settings → Open log folder**.
