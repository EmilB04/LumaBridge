> **Pre-release.** DualSense over USB confirmed working; a mouse sleep-fade fix.

## Fixed

- **DualSense lightbar over USB: confirmed working** on real hardware. Bluetooth is still
  unconfirmed - DualSense distinguishes "paired" from "connected" (the light needs to be
  solid, not off/pulsing), so a report of it failing on Bluetooth needs that checked first.
- **Devices page: the Azoth and the DualSense now always show a row when switched on**, found
  or not. Before, a device LumaBridge couldn't find had no row to click - exactly when its
  "Not found" diagnostic (added a couple of rounds ago) was needed most.
- **Logitech mouse: the sleep fade flickered instead of dimming**, for a mouse showing one of
  its own on-device effects (Breathing, Color cycle, Color wave - not a plain color). The fade
  was re-sending that effect with a falling intensity value up to four times a second, and
  each send restarts the effect's own animation from its start - looks like rapid flicker, not
  a dim. The fade now drops out of the on-device effect the instant it starts and uses the
  same smooth, already-correct per-LED or plain-color path a static color always used.
