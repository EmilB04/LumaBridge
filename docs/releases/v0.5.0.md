> **Pre-release.** RAM lighting for HyperX / Kingston FURY RGB DDR4 (experimental).

## New

- **RAM lighting (experimental).** HyperX / Kingston FURY RGB DDR4 sticks follow
  LumaBridge like the fans do, with every effect running across each stick's five LEDs.
  - RAM lighting sits on the motherboard's SMBus, which only administrators can reach. A small
    helper, `LumaBridge-RAM.exe`, does it through the signed PawnIO driver; the app starts it
    without a prompt once it's set up.
  - **Set up once** (Devices → **Memory (RAM)**): install PawnIO from pawnio.eu, put
    `SmbusPIIX4.bin` from the PawnIO.Modules releases next to `LumaBridge.exe`, click
    **Set up the helper** (administrator, once), then switch on **Light the RAM**. It's off by
    default.
  - **Safety:** finding the sticks only reads. After that, the helper writes to one address,
    the sticks' lighting controller (`0x27`), and only to its color, brightness and apply
    registers, never to the sticks' configuration chips. Details in
    [docs/peripherals.md](https://github.com/EmilB04/LumaBridge/blob/main/docs/peripherals.md).
  - AMD chipsets only for now. If the sticks flicker, Armoury Crate is lighting them too:
    switch the RAM off in Armoury Crate.
  - When LumaBridge lets go, the sticks keep the last color until Armoury Crate sets them
    again or the PC restarts.
- The dashboard's Aura devices card shows the RAM's state.
