> **Pre-release.** CS2 bomb countdown on the Azoth OLED, with a USB display test and clearer connection status.

## New

- **CS2 bomb countdown:** large remaining seconds temporarily replace the Azoth screen
  while the bomb is planted. Normal play uses an estimated 40-second fuse from the plant
  signal, adjustable for community servers. When CS2 supplies bomb timing, it is used instead.
- **Automatic screen restoration:** defuse, explosion, round changes, feed loss and timer
  expiry restore the selected clock, music mode or confirmed animation. Unknown previous
  content and custom GIFs not confirmed in the current connection return to the clock.
- **Display test:** Test countdown on keyboard runs for 10 seconds without a match, then
  restores the screen. The test is labelled separately from a real plant.
- **Countdown status:** connection, feed, sleep and display errors are shown beside the
  setting on both the CS2 game page and the Azoth OLED page.

## Changed

- **Wired USB required:** connect the cable and set the Azoth switch to wired USB mode.
  The countdown and its test do not work through the Omni / 2.4 GHz receiver. Enabling the
  option keeps the normal screen until a bomb is planted.
- **CS2 feed setup:** Update feed adds optional bomb and phase-countdown fields; restart
  CS2 afterward. Existing setups still support the estimated countdown.
- **Azoth wake handling:** display and lighting writes wait briefly after waking or turning
  the screen back on. Repeated failures to answer over USB show a cable-replug message.

## Validation

- The x64 Windows app builds and portable tests pass, including countdown timing,
  authentication, defuse handling, display rendering, restoration commands and the test timer.
- Checked the UI in Wine with simulated CS2 plant, supplied countdown and defuse events.
- The countdown has not yet been verified on a real Azoth over wired USB.
