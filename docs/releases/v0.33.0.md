> **Pre-release.** The controller page shows every input in 2D, notifications can replace a vendor's lighting runtime, and the Lighting page has a new layout.

## New

- **Every controller input in 2D:** the controller page now opens on a 2D view: the
  controller from above with held buttons lit and the stick caps moving, both triggers as
  bars, each stick's position in its own circle, fingers on the touchpad to scale,
  gyroscope and accelerometer as bars, and every button by name. The 3D model is one click
  away, and your choice is remembered. **Show numbers** adds the raw values, a few times a
  second.
- **Replace a vendor runtime from the notifications:** when Razer Synapse's Chroma runtime
  or Alienware's AlienFX sits where LumaBridge's would go, the bell shows a note with a
  **Replace vendor runtime** button. It does the same as the Integrations page: backs up
  the original (Remove puts it back) and asks for administrator approval.

## Changed

- **Lighting page:** Auto opens with a compact preview of your between-games lighting
  (manual color, rainbow, off or Armoury Crate) beside a 2D overview of your devices, with
  brightness, idle choices and game status close by. Manual shows the selected device's
  color and brightness beside its live 2D or 3D preview. Devices can be dragged into place
  in Manual's 2D view, and **Reset layout** puts them back. Smaller windows stack the cards.
