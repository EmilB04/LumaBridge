> **Pre-release.** Fixes the Hardware access update that failed or never cleared "Needs repair".

## Fixed

- **"Needs repair" stayed after clicking Update:** the setup script recorded the old helper
  version, so LumaBridge kept asking for an update.
- **Update failed with "the file is being used by another process":** the running app
  started the helper again while it was being replaced. The setup script now switches the
  helper's task off during the copy, waits for the helper to exit, and retries the copy.

## Download

**LumaBridge-v0.34.1.zip** below. Exit the running LumaBridge from the tray first, then
click **Update** under Hardware access once.
