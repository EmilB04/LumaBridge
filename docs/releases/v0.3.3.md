> **Pre-release.** The hand-back to Armoury Crate now finds and stops the real holder of
> the lighting controller, runs faster, and tells you it's working.

## Fixed

- **Hand-back still failed even after v0.3.2's fix.** Killing Armoury Crate's motherboard
  helper (`Aac3572MbHal_x86`) alone didn't release the controller: **LightingService**,
  the ASUS service the helper reports to, is what actually keeps the device open. The
  hand-back task now stops `LightingService` too when the controller is still held after
  the helper is killed, and starts it again afterwards.
- **Hand-back was slow.** The exclusive-open check used to compile a small C# helper
  (`Add-Type`) on every run, and waited a fixed 1.5 s twice regardless of how quickly the
  handle actually cleared. It now uses a plain .NET file open (no compile step) and polls
  instead of sleeping the full time.

## New

- **A countdown while the lights hand back.** Clicking "Stop controlling the lights"
  shows "Handing back to Armoury Crate... 5s" for the few seconds the controller needs to
  restart, instead of jumping straight to the final message.
