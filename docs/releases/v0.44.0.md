> **Pre-release.** Save a boot effect inside Nollie hubs, so it plays at power-on before Windows, and play it from the hub's page.

## New

- **Boot effect saved in the hub:** on the page of a Nollie hub with the OS2 firmware (such
  as the 8 channel hub), "Boot effect in the hub" writes one of the hub's eight built-in
  effects (Light up, Color wipe, Slowly wipe, Pull flower, Stackab1-3, Bullets) into the hub
  itself. The hub plays it whenever it gets power, with no program running. Set brightness,
  speed, size, delay, the pause between sweeps, up to three colors and the frame rate.
  Close Nollie's own app first.
- **Two effects:** with two or more channels set up, give each channel Effect 1 or Effect 2,
  for example the fans one effect and the strip another.
- **Play it on the hub:** shows the effect the hub holds. LumaBridge's colors stop for about
  eight seconds while the hub plays it, then come back.
- **What the hub keeps, in the log:** when a hub with the OS2 firmware is opened, LumaBridge
  asks it for its firmware, power-on behavior, LED counts and effects and writes the answers
  to the log. Nothing is changed by that.

## Changed

- **Saving also sets the hub's LED counts** to what you set up on each channel (other channels
  keep the hub's value), so the hub's own effects fit your fans. It makes the boot effect the
  first thing the hub plays at power-on.

## Fixed

- Nothing in this release fixes a bug.

## Validation

- The x64 Windows app builds with MinGW and the Linux core tests pass, covering the new
  reports, the saved settings (including settings from before this release), the channel
  order for two effects and the read-back. The published package is built with MSVC by the
  release workflow.
- Checked on an 8 channel hub with the OS2 firmware (USB 16D5:2A08, firmware 2.4.0): every
  save reads back as sent (effect, colors, speed, size, delay, pause, frame rate, channels,
  LED counts, one or two boot canvases), Play it on the hub makes the hub report that it is
  playing its boot effect, and the saved effect plays at power-on.
- Not checked: other hub models, and how the second effect and the pause look next to the
  first on real fans. The Prism8 and the 1 channel OS2 hub get the same card and use the same
  commands, but only the 8 channel hub was tried. 16 and 32 channel hubs do not get it.
