> **Pre-release.** F1 24 / F1 25 rev lights, a new built-in game feed.

## New

- **F1 24, F1 25:** rev lights from the game's own UDP telemetry, blue at low revs through
  green, yellow and red as the shift lights climb, and a fast red flash once they're full.
  Switch on UDP Telemetry in the game's settings (its page in the Games List says how).
  Built the same way as the other built-in feeds (Forza, War Thunder, ...): LumaBridge only
  reads the official telemetry packet, no DLL in the game.
