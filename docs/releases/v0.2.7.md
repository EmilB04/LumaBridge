## New: idle effects, and a working hand-back to Armoury Crate

- **Rainbow**: a new effect in Manual mode (choose how long one full color cycle takes).
- **When no game is running** (Auto mode): **My manual color**, **Rainbow**, **Off** or
  **Armoury Crate**.
- **Armoury Crate** now really hands the lights back. LumaBridge stops sending colors and
  starts Armoury Crate, which re-applies its own effect (its window opens). The same
  happens when you choose **Stop controlling the lights** (Settings or tray) and when you
  exit LumaBridge. A Windows shutdown doesn't start it; Armoury Crate takes over at the
  next boot anyway.
- "Stop controlling the lights" is remembered across restarts until you click **Resume
  lighting control**.
