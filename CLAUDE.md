# Working on LumaBridge

- **Versioning:** semantic versioning; see [docs/releases/README.md](docs/releases/README.md).
  Patch = bug fixes only, minor = new features, major = breaking changes. The version lives
  in `CMakeLists.txt`, `src/app/res/app.rc` and `src/app/res/app.manifest`.
- **Releases:** only when the owner says "yes, release vX.Y.Z". Tag names start with `v`.
- **Commits:** authored as EmilB04 <emil.berglund@live.no>, with no `Co-Authored-By` or
  session trailers.
